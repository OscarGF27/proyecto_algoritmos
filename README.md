# Contraentrega Ya

Plataforma web para pagos contraentrega y operación logística (simulada) en Colombia.

## Stack
- Next.js 14 + TypeScript
- Tailwind CSS
- Prisma + PostgreSQL
- NextAuth (Credentials)
- Vitest

## Inicio rápido
Ver `docs/especificacion.md` para alcance, arquitectura, modelo de datos, endpoints y guía de ejecución.
